Política de Privacidad

En Bvelt nos tomamos muy en serio la seguridad y la privacidad de tus datos. A continuación, detallamos de manera transparente cómo recopilamos, utilizamos y protegemos la información de los usuarios que acceden a nuestra plataforma.

1 ¿Quiénes Somos?

Bvelt es una plataforma inteligente de gestión de clientes, optimización de rutas de trabajo y automatización de marketing móvil para contratistas y profesionales de servicios locales (como HVAC, limpieza, jardinería, pintura y remodelaciones).

2 Recopilación de Información y Datos del Usuario

Recopilamos información para proporcionar mejores servicios a nuestros usuarios. Esto incluye:

  • Información de Cuenta de Usuario: Correo electrónico, nombre de perfil y foto cuando te registras a través de Google o Firebase Auth.
  • Información de Negocio: Nombre comercial, nicho, ciudad de operación, número de teléfono y enlaces de Google Business Profile ingresados voluntariamente por el usuario.
  • Datos Operativos del Negocio: Lista de leads (clientes potenciales), estimaciones visuales de costos, tareas operativas y coordenadas para la planificación óptima de rutas.

⚠️ Política de Datos de Google API (Google User Data)

Bvelt cumple estrictamente con la Política de datos de usuario de los servicios de Google API (Google API Services User Data Policy), incluidos los requisitos de Uso Limitado (Limited Use):

  • Uso de Datos: El uso y transferencia por parte de Bvelt a cualquier otra aplicación de la información recibida de las API de Google se adherirá a las Políticas de datos de usuario de los servicios de Google API, incluidos los requisitos de Uso Limitado.
  • Sin Transferencia a Terceros: No transferimos, vendemos, compartimos ni divulgamos tus datos de usuario de Google a redes de publicidad, corredores de datos ni a ningún tercero no autorizado.
  • Utilidad Exclusiva: Los datos obtenidos de tu cuenta de Google (como el nombre de perfil y correo electrónico) se utilizan únicamente para autenticar tu cuenta, crear tu perfil de contratista y sincronizar tus respuestas o gestiones de reseñas dentro de nuestra aplicación.

3 Uso y Almacenamiento Seguro

Toda la información se transmite de forma cifrada mediante protocolos de seguridad HTTPS/TLS de grado industrial. Almacenamos tus datos en Firestore (Firebase Cloud) con reglas de seguridad estrictas que garantizan que únicamente tú tienes acceso a la base de datos de tu perfil y de tus clientes potenciales.

4 Revocación de Permisos y Eliminación de Datos

Como usuario, tienes derecho en cualquier momento a:

  • Revocar el acceso de Bvelt a tu cuenta de Google desde la configuración de tu cuenta de Google (Security / Aplicaciones con acceso).
  • Solicitar la eliminación total de tu perfil, leads, rutas y datos de la base de datos de Bvelt enviando un correo electrónico directamente a nuestro equipo de soporte técnico.
